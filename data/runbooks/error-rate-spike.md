# Runbook: 에러율 급증(5xx Error Spike) 대응 절차

- incident_type: error-rate-spike
- 주요 증상: 서버 오류(HTTP 5xx) 응답 비율이 평소보다 크게 늘어난다. 주로 신규 배포 직후 코드 결함이나 설정 오류로 시작된다.

1. get_monitoring_status로 에러율 상승 시작 시점과 최근 배포 이력을 대조한다.
2. 배포 직후 시작됐다면 해당 버전을 즉시 직전 버전으로 롤백해 에러율이 떨어지는지 확인한다.
3. 롤백이 불가능하면 문제 기능을 feature flag로 끄거나 해당 엔드포인트 트래픽을 차단한다.
4. 에러 로그의 스택트레이스를 수집해 공통 예외 유형(Null 참조, 스키마 불일치 등)을 식별한다.
5. 정상화 후 배포 파이프라인에 카나리 배포 또는 에러율 기반 자동 롤백 조건을 추가한다.
